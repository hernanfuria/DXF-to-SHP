# Reglas
- No asumas nada, cualquier duda que tengas debes primero debatirla con el usuario.
- Si tenes sugerencias sobre el flujo de trabajo, resolucion del problema o implementaciones: compartilas con el usuario.
- El codigo generado debe estar estrictamente en ingles, con tantos comentarios y documentacion como sea posible.
- El codigo debe ser facil de leer y entender.
- Cuando el usuario lo pida, debes proporcionar el mensaje correspondiente a los ultimos cambios para realizar el `git commit`.
